# ResegmentArticle

Experimental tools for segmenting ALTO page data into paragraphs and refining article boundaries.

## Install for development

From this directory, install the package in editable mode:

```powershell
python -m pip install -e ".[test]"
```

This makes `segment_article` importable from notebooks and scripts outside this
project directory. Run the test suite with `pytest`.
